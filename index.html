Getting started

From install to your first prompt.

1.Install

Node.js 22.12.0 or newer. In your terminal:

$ npm install -g yew-agent-kit

The add-on includes the YEW core. YEW has no subscription on Robinhood Chain, with approval in chat and an optional daily spending limit in USD. Run yew --version to see the version you have.

2.Connect your agent

Connect directly with Node.js 22.12.0 or newer and npm on your PATH. These shortcuts run the YEW MCP server; no global install is needed if you use them.

Add to Cursor ↗ Install in VS Code ↗

Claude Code, in your terminal:

$ yew connect claude

Codex, in your terminal:

$ yew connect codex

Cursor, in your project folder's terminal:

$ yew connect cursor

Gemini, Grok and other MCP hosts: the set up guide has each one. Start a fresh session after connecting. Registering your agent ID still needs its own yes.

3.Ask your agent

Paste a first prompt — tap one to copy it:

  • What can you do with YEW? Group the tools by project.
  • Show my YEW wallet address and balances. Do not send anything.
  • Quote a swap of 5 USDG to ETH with the best route. Show the preview and do not swap yet.
  • Lend 10 USDG on Priors. Show me the preview before anything is signed.
  • Deposit 10 USDG into a Steakhouse vault. Show me the preview first.
  • Show my open positions across every project.

Every action shows a summary first, then asks for your yes or no in chat.

For builders

One MCP for the whole chain.

MCP (Model Context Protocol) is a connection for AI tools. One local connection gives your agent 35 projects and hundreds of tools on Robinhood Chain: project information, balances, swaps, bridges, lending and identity.

Your agent's tool list shows the everyday tools. For anything not listed, it calls find_tool with what it wants to do, then run_tool with the tool's name and arguments. Tools run this way get the same checks, local guard, summary and yes-or-no approval as a direct call.

Connect Claude Code, Codex, Gemini, Cursor or another compatible host. Build your own workflows and experiment with autonomous agents. Pons token launches and curve buys are one example among the project tools.

Reads work straight away. Actions need a verified ERC-8004 agent ID and your yes or no in chat. Call account to see where your setup stands. Official $YEW address: to be announced at launch.

Custody boundaries

Your wallet stays with you

Your private key never leaves your computer, and signing happens locally. YEW cannot recover a lost key — back it up yourself, offline.

Terminal-only commands

Run yew init or yew export only in your own terminal, never through the agent. If anything asks for your key or seed phrase in YEW's name, it is not YEW — stop and report it on our official X, @yewagentkit.

Approvals

Every action is summarised in plain words and waits for your yes or no in chat. Approvals match the exact amount, never unlimited. A summary shows expected changes; actual outcomes can differ.
